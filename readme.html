ABOUT THIS PROJECT

OVERVIEW

WHAT IS MEOWFRIEND

MeowFriend is a retro arcade faucet site for Meowcoin (MEWC) — a collection of minigames, a virtual pet system, and an optional Meowcoin-node-integrated backend, wrapped in a neon CRT-arcade look.

CONTENTS

WHAT'S IN HERE

  • Faucet — a small MEWC drip faucet with a cooldown timer, gated behind a sign-to-register flow so a player proves control of their own address before claiming.
  • Arcade minigames — a slot machine, a road-crossing game, and an endless runner, all sharing a single in-game ticket economy.
  • Gotchya — a persistent virtual pet with hunger/happiness/energy, weight and IQ that grow over real time, a shop for food and permanent upgrades, and a backpack for items found while playing.
  • Cat Hack — a turn-based, permadeath roguelike dungeon crawl starring your Gotchya pet, with a cemetery for pets who don't make it back.
  • Donations & registration — an optional flow for donating MEWC and registering a wallet address via cryptographic message signing, verified against a real Meowcoin node rather than trusted client-side.

TECH

HOW IT'S BUILT

Vanilla HTML/CSS/JS on the frontend — no build step, no framework — with Tailwind via CDN for utility styling. A small Node.js/Express bridge server handles anything that needs to talk to a real Meowcoin node's RPC interface. No ads.
